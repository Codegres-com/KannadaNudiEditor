Nudi Kannada Typing in MS Word

ಎಂಎಸ್ ವರ್ಡ್‌ನಲ್ಲಿ ನುಡಿ ಕನ್ನಡ ಟೈಪಿಂಗ್

Want to type Kannada in Microsoft Word with the Nudi keyboard? You can use KAGAPA's Nudi software (5.0, 6.0, 6.1) or Kannada Nudi Editor's F9 Global Mode. The key to avoiding gibberish is matching Unicode vs ASCII mode with the right font.

Start typing in Kannada – it's free

Method 1: Kannada Nudi Editor Global Mode (Unicode)

  1. Install Kannada Nudi Editor from the Microsoft Store and start it.
  2. Open Word and click in your document.
  3. Press F9 to switch to Kannada and type with Nudi keys – knfnw → ಕನ್ನಡ.
  4. Press F9 again to type English in the same document.
  5. Keep a Unicode Kannada font: Nirmala UI, Tunga, NudiParijatha or Noto Sans Kannada.

Not on Windows? Write in the online editor and click Save to download a .docx that opens in Word.

Method 2: KAGAPA Nudi 5.0 / 6.0 / 6.1 in Word

  1. Start the Nudi software; it runs in the Windows taskbar.
  2. Choose Unicode mode if your version offers it (Nudi 5.0 and later). Nudi 4.0 and older only have ASCII mode.
  3. In Word, choose the matching font: a Unicode Kannada font in Unicode mode, or a Nudi font such as Nudi 01 e in ASCII mode.
  4. Switch Nudi to Kannada from its taskbar icon and type with the same Nudi keys.

Frequently asked questions

How do I type Kannada in MS Word using Nudi 6.1?

Start Nudi 6.1, keep it in Unicode mode, open Word, select a Unicode Kannada font such as Nirmala UI and switch Nudi to Kannada. Alternatively install Kannada Nudi Editor and press F9 in Word.

How do I type in Word with Nudi 5.0?

Nudi 5.0 can type in ASCII or Unicode. Choose Unicode mode with a Unicode font for documents you will share; in ASCII mode you must use a Nudi font like Nudi 01 e.

Why do I see boxes instead of Kannada in Word?

The selected font does not contain Kannada. Select the text and change the font to Nirmala UI or Tunga.

Why does my Nudi document look like English letters on another computer?

It was typed in ASCII mode with a Nudi font that the other computer doesn't have. Convert it to Unicode with the Nudi ASCII to Unicode converter.

Can I type Kannada in Word on a Mac?

Yes – write in Kannada Nudi Editor for Mac and save as .docx, or copy the Unicode text into Word.
