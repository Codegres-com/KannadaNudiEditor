How to Type in Nudi Kannada

ನುಡಿಯಲ್ಲಿ ಕನ್ನಡ ಟೈಪ್ ಮಾಡುವುದು ಹೇಗೆ?

Nudi is the Kannada keyboard layout standardised by the Government of Karnataka and KAGAPA. Once you know three simple rules – consonant keys, vowel-sign keys and the f key for ottaksharas – you can type any Kannada word on an ordinary English keyboard.

Start typing in Kannada – it's free

How to type Kannada in Nudi – 6 steps

  1. Open the Kannada Nudi Editor in any browser – nothing to install.
  2. Make sure the Input Mode shows KAN and the Layout menu is set to Nudi/KGP (both are the default).
  3. Type a consonant key to get the full letter with the inherent “a”: k gives ಕ.
  4. Type a vowel key straight after a consonant to add the vowel sign: kA gives ಕಾ.
  5. Press f between two consonants to join them into an ottakshara: kfk gives ಕ್ಕ.
  6. Press F9 to switch between Kannada and English, then save as Word (.docx) or copy the Unicode text anywhere.

Rule 1: each consonant key types a full letter

In Nudi every consonant key already carries the vowel “a”. Lower-case and upper-case keys give related letters – usually the unaspirated and aspirated pair: k → ಕ, K → ಖ; t → ತ, T → ಥ. The full chart is below and on the printable Nudi keyboard chart.

Rule 2: vowel keys after a consonant add the vowel sign

Typed on their own, vowel keys give independent vowels (a → ಅ, A → ಆ). Typed right after a consonant they add the matching vowel sign (ಕಾಗುಣಿತ):

Rule 3: press f to make ottaksharas

The f key adds a halant (್) to the consonant you just typed. The next consonant then joins underneath as an ottakshara (vattakshara):

Use upper-case F instead when you want a visible half letter instead of a joined conjunct.

Frequently asked questions

How do I type in Nudi on a normal English keyboard?

No special keyboard is needed. Open the editor, keep the layout on Nudi/KGP and type using the key chart – for example knfnw gives ಕನ್ನಡ.

Why does f not type the letter f?

In the Nudi layout f is the halant (್) key used to join consonants. Kannada has no ‘f’ sound of its own; ಫ is on P and ಫ಼ on PX.

How do I switch between Kannada and English?

Press F9, or click the KAN / ENG switch in the toolbar.

Is Nudi different from Baraha?

Yes. Nudi is a fixed key-per-letter layout (like a typewriter); Baraha is phonetic – you spell the sound, e.g. ‘kannaDa’. Kannada Nudi Editor supports both; see Baraha typing.

Do I need to install Nudi fonts?

No. The editor produces Unicode Kannada, which every modern computer and phone can display without extra fonts.

Ready to write in Kannada?

The editor runs entirely in your browser – no sign-up, no installation.
