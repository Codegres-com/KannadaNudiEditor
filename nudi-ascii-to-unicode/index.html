What is “old Nudi format”?

Before Unicode, Kannada software such as Nudi 4.0 and Baraha stored each Kannada glyph as a Latin-1 character (À, Á, ª, £ …) and relied on a special font – Nudi 01 e, Nudi 01 k, Nudi Akshara – to draw them as Kannada. That is called ASCII or ANSI Kannada. Without the exact font, the text shows as gibberish, cannot be searched or spell-checked, and breaks on phones and websites.

Unicode gives every Kannada letter its own standard code, so it displays correctly with any Kannada font on any device. Converting Nudi ASCII to Unicode is a one-time fix for old documents.

Frequently asked questions

How do I convert Nudi format to Kannada Unicode?

Paste the old Nudi text into the left box on this page. The Unicode Kannada appears on the right; click Copy to use it anywhere.

Which fonts does this converter support?

Text typed with the Nudi ASCII fonts (Nudi 01 e, Nudi 01 k, Nudi 02 e, Nudi 05 e, Nudi 10 e, Nudi Akshara and similar). Baraha ANSI text uses a closely related encoding and usually converts as well.

Does it handle ottaksharas, arkavattu and vowel signs?

Yes. Conjuncts, ra-ottu, arkavattu, deergha and split vowel signs are rearranged into correct Unicode order.

My pasted text already shows as Kannada letters. Do I need to convert it?

If it shows correctly in any font (for example in a browser or on your phone), it is already Unicode. If it only looks right with a Nudi font selected, it is ASCII and needs converting.

Is there a file size limit?

No. Very large texts take a moment longer; for whole Word files use the editor's file conversion.
