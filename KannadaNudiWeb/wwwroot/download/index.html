Frequently asked questions

Is Kannada Nudi Editor free?

Yes, all versions are free.

How do I type Kannada on my Android phone?

Install Kannada Nudi Keyboard from Google Play and enable it as your keyboard. It works in WhatsApp, Gmail and any other app.

Is there a Kannada Nudi app for iPhone, iPad or Mac?

Yes. Kannada Nudi Editor on the App Store runs on iPhone, iPad and Mac.

Does the desktop app need internet?

No. Desktop packages run fully offline with no external dependencies.

How do I type Kannada in other Windows apps?

Install the Windows app from the Microsoft Store and press F9 to toggle Global Mode. It uses the same Nudi / Baraha key bindings as the editor in any application (except those running as Administrator).

How do I install Kannada Nudi Editor on Ubuntu or Linux?

Install Kannada Nudi Editor from the Snap Store, or run sudo snap install kannadanudi in a terminal. It works on Ubuntu and every Linux distribution with Snap support, and updates automatically.

Can I type Kannada in other Linux apps?

Yes. Keep the Linux app running and press F9 in any application to switch between English and Kannada, using the same Nudi / Baraha key bindings as the editor. It works through IBus, the standard Ubuntu input method framework, on both Wayland and X11.
