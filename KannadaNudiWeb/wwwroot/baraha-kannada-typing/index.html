Baraha-Style Phonetic Kannada Typing

ಇಂಗ್ಲಿಷ್ ಅಕ್ಷರಗಳಲ್ಲಿ ಟೈಪ್ ಮಾಡಿ, ಕನ್ನಡದಲ್ಲಿ ಪಡೆಯಿರಿ

Don't know the Nudi keyboard? Type Kannada the way it sounds, using English letters. Choose the Baraha (Phonetic) layout and kannaDa becomes ಕನ್ನಡ as you type.

How phonetic typing works

  1. Open the editor and set Layout → Baraha (Phonetic).
  2. Type consonants followed by vowels: ka → ಕ, kaa → ಕಾ, ki → ಕಿ.
  3. A consonant without a vowel stays as a half letter, so two consonants in a row form an ottakshara automatically: kka → ಕ್ಕ.
  4. Capital letters give the aspirated or retroflex sounds: t → ತ, T → ಟ, L → ಳ.

Baraha or Nudi?

Phonetic typing is quickest to learn if you are used to an English keyboard. If you already type in Nudi, or need to match office standards, use the Nudi / KGP layout instead – you can switch layouts at any time without losing your text.

Frequently asked questions

Is this the Baraha software?

No. Kannada Nudi Editor is an independent, free editor that offers a Baraha-style phonetic layout, so people familiar with Baraha transliteration can type the same way.

How do I type ಳ, ಣ and ಟ?

Use capital letters: L for ಳ, N for ಣ, T for ಟ and D for ಡ.

How do I type the anusvara (ಂ)?

Type M after the vowel, for example beMgaLuru → ಬೆಂಗಳೂರು.

Is the output Unicode?

Yes. Everything you type is standard Unicode Kannada that can be pasted into any app or website.
