Kannada Nudi Typing App for PC

Kannada Nudi Editor is a free Kannada typing app for desktop computers. It uses the standard Nudi / KGP keyboard (plus phonetic Baraha), writes Unicode Kannada, opens and saves Word files and works fully offline.

What you get

  • Nudi / KGP keyboard – the same layout as KAGAPA Nudi 6.1, so there is nothing to relearn. See the chart.
  • Baraha phonetic typing – type kannaDa to get ಕನ್ನಡ.
  • Global Mode (F9) on Windows and Linux – type Kannada directly in MS Word, Excel, PowerPoint, Chrome, WhatsApp Desktop and other apps.
  • Word-style editor – fonts, headings, tables and formulas, with Word (.docx) export.
  • Old Nudi files – open Nudi 4.0 ASCII documents and convert them to Unicode. How it works.
  • Kannada speech to text – dictate instead of typing in the online editor and mobile apps.
  • Offline and private – nothing is uploaded; no account needed.

Install and start typing on Windows

  1. Open the Kannada Nudi Editor Store page and click Get / Install.
  2. Launch Kannada Nudi from the Start menu.
  3. Type in the editor using Nudi keys – e.g. knfnw → ಕನ್ನಡ.
  4. To type in another program, leave the app running, switch to that program and press F9. Press F9 again for English.

Frequently asked questions

Is the Kannada Nudi app for PC free?

Yes. All versions – Windows, Mac, Linux, Android, iPhone and the web editor – are free.

Is this the official Nudi software from KAGAPA?

Kannada Nudi Editor is developed by Codegres with guidance from KAGAPA and uses the same Nudi / KGP keyboard layout. KAGAPA's own Nudi software is distributed separately on kagapa.com.

Does it work on Windows 7 or 8?

The Microsoft Store app needs Windows 10 or 11. On older Windows versions use the online editor in a current browser.

Can I type Kannada in MS Word with it?

Yes. Press F9 to turn on Global Mode and type in Word directly, or write in the app and save as .docx. See Nudi typing in MS Word.

Does it need internet?

No. The desktop apps work fully offline.

Ready to write in Kannada?

The editor runs entirely in your browser – no sign-up, no installation.
