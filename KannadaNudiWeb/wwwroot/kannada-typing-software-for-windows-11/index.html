Kannada Nudi Editor is a Microsoft Store app built for Windows 11 and 10. It gives you the Nudi and Baraha keyboards inside every program through Global Mode – press F9 and type Kannada in Word, Excel, Outlook, Chrome or Edge.

Set up Kannada typing on Windows 11

  1. Open the Microsoft Store page and click Install. No administrator rights or separate fonts needed.
  2. Start Kannada Nudi from the Start menu (pin it to the taskbar for quick access).
  3. Click into the app where you want Kannada – Word, Excel, Chrome, Notepad.
  4. Press F9 and type using Nudi keys: knfnw → ಕನ್ನಡ.
  5. Press F9 again to return to English.

Choose Nudi or Baraha in the app's Layout menu; Global Mode uses the same layout.

Why use it instead of the built-in Windows Kannada keyboard?

Windows 11 can add a Kannada keyboard under Settings › Time & language › Language & region, but it uses a different (InScript-style) arrangement. If you learned typing on Nudi – the layout used in Karnataka offices and typing exams – Kannada Nudi Editor keeps the keys you already know.

Frequently asked questions

What is the best Kannada typing software for Windows 11?

For Nudi or Baraha typists, Kannada Nudi Editor from the Microsoft Store is free, uses the standard layouts and types into any app with F9.

Does Global Mode work in apps run as Administrator?

No. Windows blocks keyboard helpers from elevated apps. Run the target app normally, or use the editor and copy the text.

Does Nudi 6.1 work on Windows 11?

If you prefer KAGAPA's Nudi 6.1, check kagapa.com for compatibility. Kannada Nudi Editor offers the same layout and is built for Windows 11.

Which font should I use for Kannada in Word on Windows 11?

Any Unicode Kannada font: Nirmala UI and Tunga ship with Windows; NudiParijatha and Noto Sans Kannada are free downloads.

Ready to write in Kannada?

The editor runs entirely in your browser – no sign-up, no installation.
