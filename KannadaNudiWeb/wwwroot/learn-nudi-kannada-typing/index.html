Learn Nudi Kannada Typing

ನುಡಿ ಕನ್ನಡ ಟೈಪಿಂಗ್ ಕಲಿಯಿರಿ – ಉಚಿತವಾಗಿ

Nudi typing is required for many Karnataka government jobs and is the fastest way to type Kannada once learned. Work through these five lessons – each takes about 15 minutes – using the practice box below or the full online editor.

Start typing in Kannada – it's free

Before you start

  • Hand position: left fingers on a s d f, right fingers on j k l ; – the same as English touch typing.
  • Shift matters: lower-case and upper-case keys give different letters (t = ತ, T = ಥ).
  • Think in sounds: type consonant first, then its vowel sign, exactly in the order you say it.
  • Keep the Nudi keyboard chart printed next to you for the first week.

Building speed

  1. Accuracy first: type slowly without looking at the keyboard until you make no mistakes.
  2. Copy a paragraph from a Kannada newspaper every day in the editor.
  3. Learn the common clusters as single movements: nfn (ನ್ನ), tft (ತ್ತ), sft (ಸ್ತ).
  4. Most typing tests count 25–30 correct words per minute as a pass. Practise with a timer once you are comfortable.

Frequently asked questions

How long does it take to learn Nudi typing?

Most people learn the layout in a week of daily practice and reach 20–30 words per minute within one to two months.

Is Nudi typing used in government exams?

Yes. Karnataka government offices use the Nudi (KGP) layout, and Kannada typing tests are typically taken on it. Check your exam notification for its exact rules.

Can I practise Nudi typing without installing software?

Yes. Use the practice box on this page or the full online editor; both run in the browser.

Should I learn Nudi or Baraha?

Learn Nudi if you need it for a job or exam, or want maximum speed. Baraha is easier to start with if you already think in English spellings.
