How to type Kannada online

  1. Open the editor at nudiweb.com. Input mode starts in KAN.
  2. Choose “Nudi/KGP” in the Layout menu (the default).
  3. Type using the key chart below. Press F9 any time to switch between Kannada and English.
  4. Save your work as a Word (.docx) or text file, or copy and paste it anywhere.

Nudi keyboard layout chart

In the Nudi layout every consonant key gives the full letter with the inherent “a” (e.g. k → ಕ). Typing a vowel key right after a consonant adds the vowel sign (e.g. ki → ಕಿ, kA → ಕಾ). Keys are case-sensitive.

Typing ottaksharas (conjuncts)

Press f after a consonant to add the halant and join it to the next consonant:

KeysResult
k n f n wಕನ್ನಡ
n m s f k A rನಮಸ್ಕಾರ
k r f n A q kಕರ್ನಾಟಕ
n u w iನುಡಿ

Use F (capital) instead of f when you want a visible halant (half letter) rather than a conjunct.

Frequently asked questions

Is this the same layout as Nudi 6.1?

Yes. The Nudi/KGP layout follows the Nudi keyboard standardised by the Government of Karnataka and KAGAPA, so if you learned typing on Nudi you can type here without relearning.

Do I need to install the Nudi software or fonts?

No. Everything runs in the browser and produces standard Unicode Kannada, which every modern device can display.

Is there a Kannada Nudi keyboard for Android?

Yes. Kannada Nudi Keyboard on Google Play lets you type Kannada with Nudi or Baraha layouts in any Android app.

How do I switch between Kannada and English?

Press F9, or use the Input Mode switch (KAN / ENG) in the toolbar.

Can I type Kannada in other apps like Word or WhatsApp?

Copy text from the editor and paste it anywhere. On Windows, the Microsoft Store app also has a Global Mode that lets you type Kannada directly into any application with F9.

Ready to write in Kannada?

The editor runs entirely in your browser – no sign-up, no installation.
