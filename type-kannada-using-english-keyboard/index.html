How to Type Kannada Using an English Keyboard

ಇಂಗ್ಲಿಷ್ ಕೀಬೋರ್ಡ್‌ನಲ್ಲಿ ಕನ್ನಡ ಟೈಪ್ ಮಾಡಿ

You don't need a special Kannada keyboard. Kannada Nudi Editor maps Kannada letters onto the keys you already have, in two ways: the standard Nudi layout and phonetic Baraha typing.

Start typing in Kannada – it's free

Option 1: Nudi layout (one key per letter)

Each English key gives a fixed Kannada letter – k = ಕ, n = ನ, w = ಡ – and f joins consonants. It is the official Karnataka layout and the fastest once learned.

Keys to pressResultMeaning

nmsfkArನಮಸ್ಕಾರHello

Option 2: Baraha phonetic typing (spell the sound)

Type how the word sounds in English letters: kannaDa → ಕನ್ನಡ, namaskaara → ನಮಸ್ಕಾರ. Easiest if you have never learned a Kannada layout. Switch the editor's Layout menu to Baraha. Baraha typing guide →

Try Nudi typing on your English keyboard

Practice box – press F9 to switch between Kannada and English. For saving, formatting and Word export, use the full editor.

Frequently asked questions

Can I type Kannada using an English keyboard?

Yes. Every key on a normal QWERTY keyboard is mapped to a Kannada letter in the Nudi layout, or you can spell words phonetically with Baraha. No stickers or new keyboard needed.

How do I type in Kannada keyboard on a laptop?

Open the editor in your browser and start typing – the Nudi layout is on by default. To type in other apps on Windows, install the Windows app and press F9.

Which is easier, Nudi or Baraha?

Baraha is easier on day one because you spell sounds. Nudi takes a few days to learn but is faster and is the government standard.

Does it work offline?

The desktop and mobile apps work fully offline. The web editor needs internet only to load the page.

Ready to write in Kannada?

The editor runs entirely in your browser – no sign-up, no installation.
