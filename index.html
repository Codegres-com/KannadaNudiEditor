Kannada Nudi Editor (ಕನ್ನಡ ನುಡಿ)

Free online Kannada typing tool. Write Kannada in your browser using the familiar Nudi / KGP keyboard or Baraha-style phonetic typing – no installation needed.

ಉಚಿತ ಆನ್‌ಲೈನ್ ಕನ್ನಡ ಟೈಪಿಂಗ್ ತಂತ್ರಾಂಶ. ನುಡಿ / ಕೆಜಿಪಿ ಅಥವಾ ಬರಹ ಮಾದರಿಯ ಕೀಲಿಮಣೆಯಲ್ಲಿ ನೇರವಾಗಿ ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲೇ ಕನ್ನಡ ಬರೆಯಿರಿ.

Features

  • Nudi / KGP keyboard – the standard Kannada layout used by Karnataka government offices.
  • Baraha phonetic typing – type Kannada using English letters.
  • Kannada speech-to-text – dictate in Kannada or English.
  • Nudi ASCII ↔ Unicode conversion – convert legacy Nudi documents to Unicode and back.
  • Word (DOCX) support – open and save .docx files with tables, formulas and formatting.
  • F9 toggle – switch instantly between Kannada and English input.

Also available offline

Kannada Nudi Editor is available for Windows, macOS, Linux, Android and iOS. Developed by Codegres, guided by KAGAPA.
